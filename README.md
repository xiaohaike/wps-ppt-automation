# WPS PPT 批量生成自动化宏

WPS 表格 + WPS 演示批量生成工具，使用 **WPS JS 宏（JSA）**。当前收录 **高版本 2.0**（不兼容低版本 WPS）。

> 本仓库是原 `cross-app-translator-and-office-macros` 单仓库拆分后的独立 PPT 宏仓库；单仓库入口仍保留在 [xiaohaike/cross-app-translator-and-office-macros](https://github.com/xiaohaike/cross-app-translator-and-office-macros)。

## 文件

- `ppt模板自动化函数（高版本2.0-不兼容低版本）.js`：主宏

## 环境

- 较新版本的 WPS Office（高版本 2.0 明确不保证兼容旧版 WPS）
- WPS 表格 + WPS 演示
- 使用 WPS「开发工具 → JS 宏 / 宏编辑器（JSA）」，**不是 Microsoft Office VBA**

## 使用步骤

1. 在 WPS 表格中准备数据，选中**只含数据行**的区域（不要选表头；每一行生成一页）。
2. 打开「开发工具 → JS 宏 / 宏编辑器」，新建模块。
3. 粘贴 `ppt模板自动化函数（高版本2.0-不兼容低版本）.js` 全文，保存。
4. 运行宏 **`ppt模板自动化总函数`**。
5. 选择 PPT 模板（`.ppt` / `.pptx`）。
   - 模板只保留 **1 张模板幻灯片**（最多 2 张，脚本以第 1 张为模板）。
6. 如模板用了 `#n#` 图片搜索占位符，按提示选择图片文件夹。
7. 结果默认输出到桌面：`批量生成文件__时间戳.pptx`。

## 模板占位符

- 文本占位符：`<1>`、`<2>`…… 对应选中区域第 1、2…… 个可见列。
- 直接路径图片：`@3@`，表格第 3 列填写图片路径/图片名（脚本会直接 `Fill.UserPicture`）。
- 图片搜索：`#3#`，选择图片文件夹后按表格第 3 列内容匹配文件名插入。
- 模板中的组合形状也会被递归扫描。

## 注意事项

- 选区不要包含表头；每一行生成一页。
- 占位符编号按**可见列**计算，隐藏列不计入。
- 模板文件只保留 1 张模板幻灯片；多于 2 张会被拒绝。
- 生成文件默认写到桌面；OneDrive/中文路径/权限异常时请先小数据试跑。
- 脚本未在 Microsoft Office 中验证，不保证兼容 VBA。
